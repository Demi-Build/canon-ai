## C. Plans and the write gate

- [ ] **C2 — undo the plan** restores each artifact to its pre-plan state in reverse order, as one

## D. Stop, one contract in three places

- [ ] **D1 — an agent run:** `POST /conversations/{id}/stop` mid-turn ends the stream, closes the
      provider generator so no further tokens are billed, and records the turn `cancelled` with
      what landed. (Stage 5 adds a deterministic mid-stream test; today the reviewer proved it by
      stopping a turn blocked on a permission chip.)
- [ ] **D2 — a queued job** cancels outright; a running one gets a cancel file, stops at the next
      item boundary, keeps what landed, and exits with code 3:

```bash
uv run python -m pytest tests/test_cancel.py -q -p no:cacheprovider -k "boundary or exit"
```

- [ ] **D3 — nothing changes when nobody cancels.** A clean run emits no `cancelled` or `kept`
      keys at all, which is why the byte-identity tests still pass.
